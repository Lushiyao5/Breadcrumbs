# Breadcrumbs

Breadcrumbs became the project name in v0.4.0. It describes the small traces
left through a session and leaves room for a playful suite of developer tools.

> Start with an intention. Leave yourself a trail back.

The focus companion is the first tool. Planning, context, and review tools
may follow; they should work independently and share documented local data.

The command, Python package, extension, installer, updater, and repository use
Breadcrumbs. The canonical command is `breadcrumbs`; `tlock` remains a
compatibility entry for existing users. Existing data is reused in place.

The rename is a product decision, not a trademark or domain-ownership claim.
