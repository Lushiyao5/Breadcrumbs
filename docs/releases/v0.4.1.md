# Breadcrumbs v0.4.1

A terminal-first productivity timer that keeps your goals in view and helps
you understand where you trail off.

## Keep one session across your work

Finishing a block no longer generates a new session name. Focus/custom blocks
and short/long breaks remain together through pause, recovery, and restart.
Each block keeps its own timer, reflection, and checkpoint. Start a different
session explicitly with **Ctrl+N**, or edit the name before the next block.
Existing history is retained; unrelated old blocks are not guessed into groups.

## Branches that stay where you expect

- Opens at the latest activity and follows new visits and duration updates.
- Selecting an older visit preserves your place. **End** or **Latest** returns
  to the newest activity.
- Click a visit or press **Enter** to open full, scrollable details, including
  on small terminals: logo, title/domain, timestamps, duration, precision, and
  annotation keys.
- Break spans appear in the same timeline without collecting app/browser
  metadata. Paused and closed-app gaps stay outside break duration.

## Terminal context and logos

Explicit terminal titles can show program/logo hints for Claude Code, Codex,
Python, Node.js, Git, and Neovim. Hints are labeled and affect presentation only.
They do not turn a title into a verified process or change scope classification.
Process/foreground-marker verification remains available for selected agents.

## Browser session pickup and tab reporting

- Untracked running blocks publish timer status too, independently of capture.
- A busy bridge port retries after another Breadcrumbs instance closes.
- Browser title matching handles alternate dashes and browser/profile suffixes;
  ambiguous profiles still remain unverified.
- The extension shows the last successfully reported tab title/domain.
  Turning title sharing off redacts it immediately. Stopped/stale/private/
  internal/unfocused context clears the preview.
- Awake heartbeats refresh every two seconds. Popup timer status remains
  independent of tab collection and failed tab reads.

## Update

Close any running Breadcrumbs TUI, then:

```powershell
breadcrumbs update
breadcrumbs update --status
```

After completion, reopen the app. In Chrome/Edge, **Reload** the unpacked
extension to load v0.4.1. If needed, run `breadcrumbs browser path` to check the
folder and re-pair from **Config → Browser connection**.

QA covers the requested action points, the complete Python and extension
suites, real isolated Chromium/extension/TUI/SQLite integration, and package
checks. See [action-point QA](https://github.com/SaroashDS/Breadcrumbs/blob/main/docs/QA-v0.4.1.md)
and this release commit's GitHub Actions checks.
