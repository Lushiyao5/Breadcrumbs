# Breadcrumbs v0.4.6

The PyPI distribution is **breadcrumbst**. PyPI rejected the original package
name; the application is still Breadcrumbs and the main command is still
`breadcrumbs`.

```sh
pipx install breadcrumbst
breadcrumbs
```

Or run directly with `uvx breadcrumbst`. This additional entry point opens
the same application. Python imports, saved sessions and preferences keep
their existing names. Version detection recognizes the new distribution and
falls back to legacy installations.

Native app capture supports Windows and Linux/X11. The timer and paired browser
are also usable on macOS and Wayland. The release contains the application
packages; video production files and MP4s remain excluded.
