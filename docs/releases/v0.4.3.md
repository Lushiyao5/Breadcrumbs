# Breadcrumbs v0.4.3

Activity details now stay beside your branch trail and follow your selection.
Windows updates also protect the installed package when another Breadcrumbs
window is still running.

## Activity sidebar

- The sidebar is visible when branches opens, including on compact terminals.
- Select another activity with arrow keys or a click to inspect its context.
- Enter keeps details inline. Ctrl+Enter no longer opens an activity popup.
- Escape closes the branch view directly. Latest/End still follows new activity.
- README instructions and actual app screenshots match this behavior.

## Windows update recovery

Previously pip could remove the package and then fail to replace a running
`breadcrumbs.exe`, leaving `ModuleNotFoundError` on the next command.

- The helper now waits up to two minutes for launcher locks to clear before
  starting pip. Close other Breadcrumbs windows when updating.
- If a launcher stays locked, no packages are changed and the status explains
  how to retry.
- The helper saves the application package and its metadata first and restores
  them if installation fails. Application updates no longer force reinstall
  all dependencies.
- The browser-extension refresh still runs after a successful update.

## Validation

Regression tests cover a locked launcher without starting pip, restoration
after an interrupted uninstall, persistent sidebar selection, latest activity
following, and session identity across focus and break blocks.
