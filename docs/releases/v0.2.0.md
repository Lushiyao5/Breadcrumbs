## A quieter focus screen

- Timer and intentions now take the main screen. The large logo, slogans, pet controls, and history sidebar have been removed.
- Press `H` to read recent sessions, full intentions, reflections, and ratings.
- The companion is optional and hidden by default. Enable it in Settings.
- Intention drafts save automatically, including before a timer starts.
- Unfinished tasks and notes carry into the next block; checked tasks stay in the completed session's history.
- Press `E` to edit intentions and `Escape` to return to timer controls. The command bar shows editing shortcuts while the editor has focus.
- Smaller terminals use a scrolling layout, and dialogs resize to fit the terminal.
- Settings, history, and reflection dialogs follow the selected theme.

Existing session history is preserved. The local database adds a table for intention drafts.

### Update

```powershell
tlock update
```

After the background update finishes, check it with `tlock update --status` and reopen Tlock.
