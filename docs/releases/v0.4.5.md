# Breadcrumbs v0.4.5

This small follow-up keeps Latest pinned when a branch list recalculates its
wrapped row heights. It builds on v0.4.4's logo, demo, simpler installation and
contributor tickets.

- Watch the actual list's virtual dimensions and scroll to the newest visit
  after layout settles, while preserving older selections.
- Cover narrow-terminal width changes in the branch regression test.
- Await screen mounting so Windows/Python 3.11 checks exercise the completed
  UI rather than a partially constructed screen.

The supplied music-backed launch and complete feature guide remain available
with the [v0.4.4 release](https://github.com/SaroashDS/Breadcrumbs/releases/tag/v0.4.4).

Native capture supports Windows and Linux/X11. macOS and Wayland can use the
timer and paired browser. PyPI publication still awaits the owner's trusted
publisher setup; the documented pipx/uvx release-wheel routes work now.
