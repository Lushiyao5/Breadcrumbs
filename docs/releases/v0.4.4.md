# Breadcrumbs v0.4.4

The supplied bread-and-branch logo now appears in the terminal header and
welcome tour. The README leads with a short working demo and an isolated
package install, with platform limits visible before installation.

## Branding and onboarding

- Preserve the original supplied logo in the repository and README.
- Render its bread mark as terminal-native colour cells without requiring
  image protocols, a graphics library, or network access at runtime.
- Show a larger mark on the first welcome-tour page. Keep the compact header
  within its existing three rows so timer and branch layouts retain their space.
- Refresh the browser-extension manifest version with this release.

## Installation and contribution

- Document a verified `pipx` / `uvx` wheel install without a Git checkout.
- State native foreground capture support up front: Windows and Linux/X11.
  macOS and Wayland users can use the timer and paired browser without native
  foreground app capture.
- Add concrete contributor tickets and publishing setup instructions.
- PyPI publication requires the repository owner's authenticated publisher
  setup; a bare package-name install is not advertised as live prematurely.

## Product demonstrations

- Add a short README GIF around intentions, starting a block and reading the trail.
- Rebuild the launch video around the real branch trail and supplied logo.
- Expand the guide to cover the timer, scope, extension, annotations, breaks,
  reflection, recovery, export, themes and optional settings.
- Use the supplied music at an audible level with measured delivery loudness,
  action-linked effects and native 1920×1080 vector UI captures.

## Validation

The Python suite passes 155 tests. Compact onboarding and session tests also
pass after the welcome logo change. The real browser integration checks tab
identity, titles, session recovery and remote timer controls with an isolated
profile and database.
