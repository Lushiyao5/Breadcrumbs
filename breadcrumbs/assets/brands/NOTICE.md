## Simple Icons

The following SVGs come from [Simple Icons](https://github.com/simple-icons/simple-icons),
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/):

- youtube.svg, spotify.svg, googlechrome.svg, firefoxbrowser.svg, openai.svg,
  github.svg, python.svg, nodedotjs.svg, git.svg, neovim.svg: Simple Icons 13.0.0, tag object
  `4c7196e9953515478cde45dfd47a842bfcd85bb5`.
- claude.svg: Simple Icons commit
  `30053a0f492fd192740ad001031b3091be060986`.

The unmodified monochrome SVGs are retained alongside generated raster masks.
The local copy of the license is LICENSE-SIMPLE-ICONS.txt.
Brand names and trademarks remain with their respective owners.

## Microsoft Codicons

vscode.svg, terminal.svg, and window.svg come from
[Microsoft Codicons](https://github.com/microsoft/vscode-codicons), commit
`5a6ad49557af022f97987cb3cfc3412b5d03f554`, files
`src/icons/vscode.svg`, `src/icons/terminal.svg`, and `src/icons/window.svg`.

Creator: Microsoft and the Codicons contributors.
License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The full license is retained in LICENSE-CODICONS.txt.

The original vectors are retained without path changes. Generated masks resize
them to 16x16 and 4x4 pixels, threshold the alpha channel, and apply a single
display color. Those terminal representations are adaptations. No endorsement
by Microsoft or the Visual Studio Code team is implied.
